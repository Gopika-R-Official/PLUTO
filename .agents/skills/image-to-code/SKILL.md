# Image-to-Code Workflow

Translate high-fidelity visual references, UI benchmarks, and wireframes into clean, accessible, componentized frontend code.

## Principles
1. **Reference-First**: Generate or inspect visual references for key screens (desktop and mobile) prior to building or refactoring complex views.
2. **Component Mapping**: Decompose visual designs into clear layout containers, typography scales, tokens, and atomic interactive elements.
3. **Responsive Parity**: Ensure mobile adaptations retain full functional capability while accommodating narrow viewports with appropriate tap targets (>= 44px).
4. **Code Quality**: Maintain semantic HTML, strict TypeScript typing, state management conventions, and accessibility standards.
